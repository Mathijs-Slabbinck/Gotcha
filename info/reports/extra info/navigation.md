# Navigation / Areas

## Unauthenticated
The pages before a user is logged in.

**On navbar:**
- Login (Index)
- Signup
- Contact
- Info

**Not on navbar:**
- Reset Password (via email)

## Authenticated

### User
For a user that has logged in but didn't select a game yet.

**On navbar:**
- Home (profile)
- Games
- User Settings
- Unlock Features (store)

**Not on navbar:**
- New Game (via button on games tab)

### Player
For a user that has logged in and has selected a game (in game view).

#### Ongoing Games
**On navbar:**
- Target Info
- Confirm Kill
- Settings

**Sometimes on navbar:**
- Admin (only for admins)

#### Finished Games
- Match Results

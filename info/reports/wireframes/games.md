# Games

The games page is for the User (when logged in but not in game)

**The Games page has 4 sections**
- Pending Games (section with list of games that haven't started yet)
- Active Games (section with list with active games)
- Finished Games (section with list with finished games)
- create new game (button to create a new game)

The lists will show some info about the games (for example if your are alive or not in active games / Kill Amount / etc)
The user can select a game to enter a game if it's still active or go to the game info page if not.

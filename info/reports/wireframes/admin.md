# admin

The admin page is for the Player (when logged in and in game that is still ongoing, where the player is admin).

### The admin will be able to:
**before the game starts:**
- Let players know they need to change their image
- Let players know they need to change their username
- Remove players from the lobby
- Add or remove admin role from players
- Toggle spectator mode for players
- Invite players (generate link)
- Change all game settings (depending on plan)
- start the game

**during the game:**
- cancel kills (that are not yet confirmed)
- Add or remove admin role from players
- Toggle spectator mode for players
- enable Assassin gamemode (if unlocked)
- enable Chaos gamemode (if unlocked)
- change Chaos gamemode timer min/max (if unlocked)
- enable timed kills (if unlocked)
- change timed kills timer (if unlocked)
- end the game early

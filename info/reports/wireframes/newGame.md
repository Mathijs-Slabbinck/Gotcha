# new game

The New Game page is for the User (when logged in but not in game)

The Page has a form the following fields:

- input[type=text] **Name**
- textarea **custom rules**
- checkbox **show player images**
- checkbox **enforce player images**
- checkbox **show gender**
- checkbox **show real names**
- checkbox **show user names**
- checkbox **Show hunter**
- checkbox **Show living players count**
- checkbox **Show living player names**
- checkbox **Show living players names to death**
- checkbox **Assassin mode**
- checkbox **Chaos mode**
- input[type=time] **Chaos mode timer min**
- input[type=time] **Chaos mode timer max**
- checkbox **Timed kills**
- input[type=time] **Timed kills timer**
- checkbox **Custom kill methods**
- input[type=text] **Custom weapons**

It also has a button to generate a join link.
